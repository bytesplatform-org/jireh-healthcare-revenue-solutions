## Sitemap

`/sitemap.xml` is generated by `app/sitemap.ts`, which scans `app/` for `page.tsx` files at build time — a new page is listed automatically, no edit needed. When adding a page:

- If it should **not** be indexed (drafts, concepts), give its metadata `robots: { index: false, follow: false }` — the sitemap skips it.
- If it is a **dynamic route** (`[slug]`), the scan can't see its URLs: add them to `EXTRA` in `app/sitemap.ts` (or extend it to read the same data the page uses).
- To weight it, add the route to `PRIORITY` in `app/sitemap.ts` (default 0.7).
- After adding a page, run `npm run build` and check `/sitemap.xml` lists it.
